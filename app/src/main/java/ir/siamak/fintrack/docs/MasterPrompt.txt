# توسعه فاز دوم پروژه حسابدار (FinTrack)

## ماژول حسابدار فروشگاه (Store Accounting Module)

---

## نقش شما

شما یک Senior Android Engineer متخصص Kotlin و Jetpack Compose هستید.

وظیفه شما توسعه فاز دوم اپلیکیشن:

```
FinTrack
```

با نام:

```
Store Accounting Module
```

است.

این ماژول مربوط به مدیریت مالی فروشگاه‌ها است و باید به صورت مستقل داخل پروژه موجود اضافه شود.

```

# قوانین مهم توسعه

1. هیچ فایل موجود حذف نشود.

2. هیچ Package موجود تغییر نکند.

3. تمام قابلیت‌های جدید فقط زیر:

```
ir.siamak.fintrack.store
```

قرار بگیرد.

4. قبل از ساخت هر فایل ابتدا ساختار بالا بررسی شود.

5. نام فایل‌ها و Package ها قابل تغییر نیستند.

6. منطق Business داخل ViewModel ممنوع است.

7. محاسبات مالی فقط در UseCase انجام شود.

8. Repository فقط مسئول دسترسی داده است.

9. UI فقط مسئول نمایش و Event ارسال کردن است.

10. تمام State ها باید Immutable باشند.

# خروجی نهایی مورد انتظار

در پایان این فاز باید کاربر بتواند:

✅ فروشگاه ایجاد کند
✅ برند ثبت کند
✅ کالا تعریف کند
✅ مواد اولیه مدیریت کند
✅ فروش سریع ثبت کند
✅ فاکتور PDF دریافت کند
✅ فروش نقدی داشته باشد
✅ فروش اقساطی داشته باشد
✅ سفارش اختصاصی ثبت کند
✅ مواد مصرفی سفارش را مدیریت کند
✅ پیش پرداخت دریافت کند
✅ وضعیت سفارش‌ها را پیگیری کند
✅ در زمان فروش هزینه در صورت تسویه شدن به مقدار کیف پول/حساب انتخابی افزوده شود
✅ برای استفاده اول برای کاربر آموزش تصویری درست و استاندارد ببیند بعد برنامه را استفاده کند

این سند، قرارداد توسعه فاز دوم حسابدار فروشگاه است و تمام توسعه‌های بعدی باید بر اساس همین ساختار انجام شود.
