# FinTrack Glossary

This document defines the terminology used throughout the FinTrack project.

The purpose is to ensure a common language across developers, designers, testers, contributors, and documentation.

---

# Account (Wallet)

A financial container representing a source or destination of money.

Examples

- Cash
- Bank Account
- Credit Card
- Digital Wallet

---

# Transaction

A financial operation that changes the balance of an account.

Examples

- Income
- Expense
- Transfer

---

# Income

Money entering an account.

Examples

- Salary
- Bonus
- Gift
- Investment Return

---

# Expense

Money leaving an account.

Examples

- Food
- Transportation
- Shopping
- Bills

---

# Transfer

Movement of money between two accounts without affecting total assets.

---

# Member

A person associated with transactions.

Examples

- Self
- Spouse
- Child
- Parent

---

# Tag

A user-defined label attached to a transaction for filtering and reporting.

Examples

- Vacation
- Business
- Health
- Education

---

# Category

A predefined classification of a transaction.

Examples

- Food
- Housing
- Transportation
- Entertainment

---

# Dashboard

The application's main overview screen presenting key financial indicators.

---

# KPI

Key Performance Indicator.

A measurable metric representing financial status.

Examples

- Monthly Income
- Monthly Expense
- Savings
- Cash Flow

---

# Report

A filtered analytical view of financial data.

Examples

- Monthly Report
- Wallet Report
- Member Report
- Tag Report

---

# Budget

A planned spending limit for a period.

---

# Financial Goal

A target the user wants to achieve financially.

Examples

- Buy a Car
- Emergency Fund
- Vacation

---

# Installment

A recurring payment toward a financial obligation.

Examples

- Loan
- Mortgage
- Credit Card
- Financing

---

# Reminder

A scheduled notification related to financial events.

Examples

- Installment Due
- Budget Limit
- Daily Logging

---

# Workspace

A logical environment containing financial data.

Future versions may support multiple workspaces.

---

# Offline First

A design principle where the application works without an internet connection.

---

# Cloud Sync

Synchronization of local data with cloud storage.

---

# Backup

A copy of user data that can be restored later.

---

# Export

Converting data into external formats.

Supported formats may include

- PDF
- Excel
- CSV
- JSON

---

# Import

Loading external financial data into FinTrack.

---

# Premium

Paid features providing advanced capabilities beyond the free version.

---

# AI Assistant

An intelligent system capable of understanding user questions and providing financial recommendations.

---

# Financial Health Score

A calculated indicator representing overall financial condition.

---

# Cash Flow

The movement of money into and out of accounts during a specific period.

---

# Repository

Architecture layer responsible for abstracting data sources.

---

# Use Case

A single business operation in the Domain layer.

Examples

- Add Transaction
- Update Wallet
- Delete Member

---

# ViewModel

Presentation layer component responsible for preparing state for the UI.

---

# StateFlow

Reactive state container used by ViewModels to expose immutable UI state.

---

# Room

SQLite abstraction library used for local persistence.

---

# Hilt

Dependency Injection framework used throughout the project.

---

# DataStore

Modern Android solution for storing application preferences.

---

# Material Design 3

Google's latest design system used throughout the application.

---

# RTL

Right-to-Left layout direction used for Persian user interfaces.

---

# Persian Calendar

The official calendar system used as the primary calendar inside FinTrack.

---

# Dynamic Color

Material You feature that adapts application colors based on the user's wallpaper.

---

# Clean Architecture

Architectural pattern separating Presentation, Domain, and Data layers.

---

# MVVM

Model-View-ViewModel architecture used by the Presentation layer.

---

# Single Source of Truth

Architecture principle where one component owns each piece of application state.

---

# Semantic Versioning

Versioning format used by FinTrack.

```
MAJOR.MINOR.PATCH
```

Example

```
2.4.1
```

---

# Long-Term Definition

FinTrack is an Offline-First Personal Financial Management Platform designed for Persian-speaking users, built with modern Android architecture and prepared to evolve into an AI-powered financial assistant.
