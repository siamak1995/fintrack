# UX Principles

---

# مقدمه

تجربه کاربری (User Experience) در FinTrack بر اساس اصل «سادگی، سرعت و شفافیت» طراحی شده است.

هدف این پروژه کاهش زمان ثبت اطلاعات مالی، افزایش خوانایی داده‌ها و ایجاد تجربه‌ای روان برای کاربران فارسی‌زبان است.

---

# اصول طراحی

- سادگی
- سرعت
- حداقل کلیک
- خوانایی
- دسترسی آسان
- ثبات در رابط کاربری
- کاهش خطای کاربر

---

# طراحی برای کاربران ایرانی

FinTrack از ابتدا برای کاربران فارسی‌زبان طراحی شده است.

ویژگی‌ها

- RTL واقعی
- فونت فارسی
- تقویم شمسی
- نمایش اعداد فارسی
- قالب‌های تاریخ ایرانی
- واحد پول تومان

---

# قانون سه کلیک

کاربر باید بتواند مهم‌ترین عملیات را حداکثر با سه کلیک انجام دهد.

نمونه‌ها

- ثبت تراکنش
- ثبت حساب
- ثبت عضو
- مشاهده گزارش

---

# سرعت ثبت اطلاعات

تمام فرم‌ها باید کمترین تعداد فیلد ممکن را داشته باشند.

از

- Dropdown
- Chip
- AutoComplete
- BottomSheet

برای کاهش زمان ورود اطلاعات استفاده می‌شود.

---

# طراحی فرم‌ها

- عنوان واضح
- گروه‌بندی اطلاعات
- اعتبارسنجی لحظه‌ای
- پیام خطای قابل فهم
- دکمه ذخیره همیشه قابل مشاهده

---

# رنگ‌ها

سبز

- درآمد
- موفقیت
- افزایش موجودی

قرمز

- هزینه
- هشدار
- حذف

آبی

- اطلاعات
- عملیات عمومی

بنفش

- گزارش
- تحلیل

نارنجی

- هشدارهای مالی

---

# تایپوگرافی

سلسله مراتب متن

- Display
- Headline
- Title
- Body
- Label

استفاده از Material 3 Typography

---

# آیکون‌ها

تمام آیکون‌ها باید

- ساده
- قابل فهم
- هماهنگ با Material Design

باشند.

---

# Navigation

اصول

- قابل پیش‌بینی
- بدون پیچیدگی
- بدون بن‌بست
- امکان بازگشت آسان

---

# Bottom Navigation

فقط صفحات اصلی

- Dashboard
- Transactions
- BaseInfo
- Reports

در Bottom Navigation نمایش داده می‌شوند.

---

# Empty State

تمام صفحات بدون داده باید شامل

- تصویر
- توضیح
- دکمه ایجاد اولین رکورد

باشند.

---

# Loading

هنگام بارگذاری

- Skeleton
- Progress Indicator

نمایش داده می‌شود.

---

# Error State

نمایش

- علت خطا
- راهکار
- دکمه تلاش مجدد

---

# Snackbar

برای

- موفقیت
- هشدار
- اطلاع‌رسانی

استفاده می‌شود.

---

# Dialog

تنها برای

- حذف اطلاعات
- عملیات حساس
- تأیید نهایی

استفاده می‌شود.

---

# BottomSheet

برای

- انتخاب گزینه‌ها
- فیلترها
- عملیات سریع

استفاده می‌شود.

---

# Accessibility

رعایت موارد زیر الزامی است.

- اندازه مناسب متن
- کنتراست رنگ
- پشتیبانی از Screen Reader
- Touch Target حداقل 48dp
- Content Description برای آیکون‌ها

---

# Dark Mode

تمام صفحات باید

- Light
- Dark
- Dynamic Color

را پشتیبانی کنند.

---

# Responsive Design

رابط کاربری باید برای

- Mobile
- Foldable
- Tablet

بهینه باشد.

---

# Dashboard UX

داشبورد باید در کمتر از پنج ثانیه مهم‌ترین وضعیت مالی کاربر را نمایش دهد.

---

# Reports UX

تمام گزارش‌ها باید

- قابل فیلتر
- قابل مرتب‌سازی
- قابل اشتراک‌گذاری
- قابل Export

باشند.

---

# اصول آینده

در نسخه‌های آینده تجربه کاربری باید برای تعامل با دستیار هوشمند مالی نیز بهینه شود تا کاربران بتوانند از طریق گفتگو، اطلاعات مالی خود را مدیریت و تحلیل کنند.
